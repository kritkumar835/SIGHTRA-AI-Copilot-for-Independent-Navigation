Voice Commands

SightGuide is audio-first. Tap anywhere on the screen and speak any of these commands:

"Describe" Describes layout & clock positions
"Read this" Reads signs, room numbers, text
"Find washroom" Guided 360° scanning loop
"Find exit" Guided scan for exit doors/signs
"Obstacles" Toggle hazard alerts & buzzes
"Repeat" Re-speaks the last message
"Stop" Cancels speech and active scan

Haptics: Single buzz = command heard. Double buzz = target found. Long buzz = hazard alert.
